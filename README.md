# AI v knihovnách

Interaktivní průvodce workshopem pro české veřejné, obecní a městské knihovny.

## Použití

Otevřete [web workshopu](https://rejcom.github.io/ai-v-knihovnach/), případně stáhněte repozitář a otevřete `index.html` v prohlížeči.

Web obsahuje pět výukových bloků, 15 kopírovatelných promptů, 10 cvičení, cvičná syntetická data, doprovodné materiály a režim promítání. Promítání ovládejte šipkami, klávesou Esc jej zavřete.

Poznámky u cvičení se ukládají pouze do místního prohlížeče. Lze je stáhnout jako text. Nevkládejte osobní údaje čtenářů. Externí zdroje a načtení písem vyžadují internet. Základní obsah funguje i bez připojení s náhradním písmem.

## Úpravy

- `index.html`: struktura a úvodní stránka
- `style.css`: vzhled, mobilní zobrazení a tisk
- `app.js`: výukové moduly, cvičení a interakce
- `data.js`: prompty a podklady pro promítání
- `materialy/`: původní doprovodné dokumenty a cvičná data

Statický web bez sestavení a bez serverového zpracování. GitHub Pages publikuje větev `main` z kořenového adresáře.

## Organizace dne

Začátek v 9:00, oběd 12:15–12:45. Jedna dopolední a jedna odpolední přestávka, každá 15 minut. Výukové bloky nemají předepsaný začátek ani délku.

## Copilot Chat a doporučená publikace

Základní postupy počítají s pracovním Copilot Chatem. Funkce závisejí na licenci a nastavení organizace; pro dokumenty je připravena i varianta s vloženým výňatkem. NotebookLM je volitelná alternativa.

Karel Klatovský: [133 tipů pro AI v knihovnách](https://ai.klatovsky.cz/knihovny/). Web odkazuje na vybrané původní tipy; nekopíruje celou publikaci ani její zadání. Technické podmínky dokládají odkazy na Microsoft Learn přímo u postupu.
